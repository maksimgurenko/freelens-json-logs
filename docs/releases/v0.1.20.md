Readable logs adds configurable JSON-log reading to **Freelens 1.10.3**.

- Compact application time, severity and message, with complete fields and exact original-text copying.
- Saved formatting profiles with configurable field paths, timestamp units and severity mappings; manual selection or automatic matching by namespace, Pod labels and container.
- Inline, Side and Bottom inspection, literal Find, anchored scrolling, Pause/Resume and manual Refresh.
- Routine refreshes no longer insert a flashing snapshot banner or move the logs. Bottom inspection occupies no space until a record is selected.
- Preserved settings across updates, explicit recovery backups, and Pod/container lifecycle handling.

## Install

Download **freelens-readable-logs-0.1.20.tgz** from this release's assets. Do not use GitHub's automatically generated source-code archives as the extension package.

1. Fully quit/reopen Freelens and open **Extensions before opening a cluster**.
2. For an update, uninstall the old extension and wait for removal. Saved settings are retained.
3. Install the downloaded `.tgz` once, wait for **0.1.20 / Enabled**, then open your cluster.
4. Open a Pod's details and select **Readable logs** beside the native Logs action.

See the [installation and maintenance guide](https://github.com/maksimgurenko/freelens-json-logs/blob/v0.1.20/docs/local-development.md#supported-local-maintenance), including the process-local filesystem-polling launch used for the verified installation.

With both assets downloaded into one directory, verify the package with:

```sh
sha256sum --check SHA256SUMS
```

## Scope and validation

Supported host: **Freelens 1.10.3**, verified on Arch Linux/Wayland. The viewer reads bounded current-instance snapshots for one Pod/container, retaining at most 1,000 records and 5 MiB of original UTF-8 text. It does not provide streaming or multi-Pod aggregation.

The release passed **100 tests**, TypeScript checks, package inspection and reproducible builds, plus the [installed-host acceptance checks](https://github.com/maksimgurenko/freelens-json-logs/blob/v0.1.20/docs/verification/19/README.md) for refresh, lifecycle, profiles, inspection, clipboard, configuration recovery and responsiveness.
