Readable logs 0.1.38 updates the guides and package validation for the Freelens 2 extension.

- The usage guide uses the controls shown in the app, including **Edit profiles**, **Back to logs**, and **Search history**.
- Links in the packaged guides open either an included document or its GitHub page. The package check verifies relative inline links before publication.
- The developer guide covers the Ralph runner's GitHub Issues queue.

## Install

Download **freelens-readable-logs-v2-0.1.38.tgz** and **SHA256SUMS** from this release's assets. Verify them in the same directory.

```sh
sha256sum --check SHA256SUMS
```

In a fresh Freelens 2 session, open **Extensions** before opening a cluster. Uninstall the previous v2 entry, install the new archive once, and wait for **0.1.38 / Enabled**. Profiles, preferences, and backups stay in the v2 settings directory. [Installation guide](https://github.com/maksimgurenko/freelens-json-logs/blob/v0.1.38/README.md#install)

The package declares Freelens `^2.0.0`. The exact release archive passed checks
on official Freelens 2.0.0 Linux amd64, including settings recovery, clipboard,
Find, and worker shutdown. Its SHA-256 is
`0a64777d1ba537c5d69889778b5d6d3dc8c4ca0a98731629c5bfa5a9d44d6074`.
Windows and macOS remain unverified.
