# Prototype visual reference

This throwaway branch inherits Freelens v1.10.3 rather than establishing a new product identity. Mode: Operate.

Use the pinned host's dark surfaces (`#1e2124`, `#262b2f`), black log canvas, light foreground, teal (`#00a7a0`) active controls, compact selectors and checkboxes, and monospace log data. Keep container/search above logs and timestamp/word-wrap controls below. Added formatting controls should occupy a small secondary row. Self-host the upstream Roboto regular font; use the host's `Lucida Console, Monaco, Consolas, monospace` log stack.

Keep three inspection structures switchable: inline expansion, side inspector, and bottom inspector. The rest of the host vocabulary stays fixed so layout is the variable being evaluated. Variant choice, row expansion and scrolling policy remain proposals until the maintainer reacts.

The built-in reference mode is a source-based reconstruction, not an embedded or live native viewer. The extension prototype is a separate cluster page; it does not acquire dock-tab behavior by looking similar.
